# Predictive Modeling of Epileptic Seizure Detection Using Machine Learning

This project implements machine learning models to detect epileptic seizures using EEG data from the BEED dataset. Random Forest achieved the highest accuracy (~98%), outperforming Logistic Regression and XGBoost.

## Key Highlights
- 98% accuracy in seizure classification
- EEG-based clinical prediction
- Reproducible pipeline using R

## Dataset
Bangalore EEG Epilepsy Dataset (BEED) from UCI repository.

## Models Used
- Logistic Regression
- Random Forest
- XGBoost
