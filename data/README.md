# Dataset Information

This folder contains the BEED (Bangalore EEG Epilepsy Dataset).

Source:
UCI Machine Learning Repository  
https://archive.ics.uci.edu/dataset/1134/beed:+bangalore+eeg+epilepsy+dataset

Description:
The dataset includes EEG signal features (X1–X16) and a target variable (y) indicating seizure activity.

Note:
The dataset is used strictly for academic and research purposes.
